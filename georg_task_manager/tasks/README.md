### Gesture tasks for georg_task_manager

Tasks for calling ros2 action clients via task manager

Individual files for seperated gesture calls:
- point_to.py
- greet_person.py
- look_at.py
- offer_hand.py
- open_hand.py
- close_hand.py
- locate_object.py

General file for standard access independent of desired gesture:
- gesture.py\
_locate\_object_ requires 3D vector relative to face camera
